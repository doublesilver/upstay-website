## 3. 인수 시 합의 5조항

외주 책임 한계 보호 — 클라이언트 동의 후 인수 진행.

### 조항 1: In-Scope 한정
인수 시점에 동작하는 기능은 WORK_ZONES.md + QUESTIONS.md 확정 항목으로 한정합니다. 영업 확장·신규 기능·기존 기능의 큰 변경(예: 견적 폼 신설, 다국어 지원, 결제 통합)은 별도 견적의 Side CR로 처리합니다.

### 조항 2: 호스팅·외부 서비스 비용 정책
- OCI(Oracle Always Free) — agora VM 공유, 외주 측 계정. **무료 한도 안**에서 운영. 한도 초과 시 외주와 협의.
- Cloudflare (DNS·CDN·R2) — 클라이언트 계정. R2 무료 10GB 안에서 운영. 한도 초과 시 클라이언트 부담.
- 도메인(upstay.co.kr) — 클라이언트 자산.
- TLS 인증서 — Let's Encrypt 무료 자동 갱신.

### 조항 3: 인계 자산
다음 자산은 클라이언트로 이관됩니다.
- [ ] GitHub `doublesilver/upstay-website` private repo 권한
- [ ] Cloudflare R2 토큰 (img.upstay.co.kr bucket)
- [ ] OCI SSH 키 (`oci_agora_key`) — 외주 계정 의존도, 인수 후 클라이언트 의향에 따라 별도 VM 이전 가능
- [ ] 환경변수 (`ADMIN_PW`, `JWT_SECRET`) — 인수 시점 즉시 클라이언트가 교체
- [ ] DB·uploads 자료 (`/home/ubuntu/upstay/data/`)
- [ ] R2 객체 (9849 파일, 약 1.3GB)

### 조항 4: 하자보수 범위 (30일)
인수 후 30일간 하자보수(무상) 범위:
- 인수 시점에 동작했던 기능이 갑자기 동작 중단
- 인수 시점에 발견되지 않은 명확한 버그
- 인수 시점 보안 패치 (의존성 critical 발생 시)

다음은 하자보수 외 (별도 견적):
- 신규 기능·UI 변경·디자인 수정
- 콘텐츠 추가·카피 변경
- 영업 확장 (다국어, 결제, 회원가입 등)
- 인프라 이전·확장 (별 VM, 비용 발생)

### 조항 5: 인수 후 책임 한계
인수 후 30일 경과 또는 클라이언트의 핵심 자산 수정(코드 직접 변경, 환경변수 수정, DB 직접 수정 등) 후 발생한 이슈는 외주 책임 범위 외입니다.
